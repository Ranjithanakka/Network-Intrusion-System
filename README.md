# Network Intrusion Detection System

## Project Description
This project is a Network Intrusion Detection System developed using Python and Machine Learning.

It analyzes network data and uses machine learning techniques to detect possible network intrusions.

## Technologies Used
- Python
- Tkinter
- NumPy
- Pandas
- Scikit-learn
- Keras / TensorFlow
- Matplotlib

## Features
- Load network datasets
- Data preprocessing
- Feature selection
- Train machine learning models
- Predict network intrusions
- Display prediction results
- Graphical User Interface using Tkinter

## Project Type
PG Academic Project

## How to Run
1. Install Python.
2. Install the required Python libraries.
3. Open `IDS.py`.
4. Run the program.
